# 같은 입력, 다른 구조·컨텍스트, 다른 출력

같은 주의 같은 일기·영상을 넣고, 에이전트 구조나 컨텍스트 요소만 바꿨을 때 한 문항의 출력이 어떻게 달라지는지 비교한다.
K-DST 문항 원문은 저작권 때문에 〈문항 원문 비공개〉로 가렸다. 반복 0회차 결과.
